# Linux System Health Monitor

This Bash script monitors and displays basic Linux system health information, including system details, resource usage, network connectivity, and top CPU-consuming processes.

## Features

- Displays hostname, operating system, kernel version, and system uptime
- Monitors CPU usage
- Monitors memory usage
- Monitors disk usage
- Displays the system's local IP address
- Checks internet connectivity
- Displays the top processes consuming CPU resources

## Getting Started

**1. Clone the repository:**
```bash
git clone https://github.com/<your-username>/system-health-monitor.git
```
**2. Navigate into the project folder:**
```bash
cd system-health-monitor
```
**3. Make the script executable:**
```bash
chmod +x system_health.sh
```
**4. Run the script:**  
```bash
./system_health.sh
```
